About Tincture

Tincture is a colour-palette studio for designers and front-end developers. It's built on OKLCH, a perceptual colour space where equal steps in lightness actually look equal to the eye. That makes it much easier to build palettes that feel balanced and accessible than working in HSL or hex.

Pick a base colour on the hue disc (hue around the edge, chroma outward), choose a harmony such as complementary, triadic or analogous, and Tincture builds a matching palette. Shuffle to explore and lock the swatches you want to keep. For every colour it generates a full 50 to 950 tonal ramp, like the scales used in Tailwind and modern design systems, spaced evenly in perceived lightness.

A contrast grid shows the WCAG 2 ratio for every text-on-background pair, marked AAA, AA or large-text only, so you can see at a glance which combinations are readable. Colour-blind previews simulate how the palette looks with common types of colour vision deficiency. An in-use preview applies the palette to light and dark surfaces. When you're happy, copy the palette as CSS custom properties or JSON. Everything runs locally in your browser.

How to use it

  1. Drag on the hue disc or set L, C and H to choose a base colour.
  2. Pick a harmony, then press Shuffle (or Space) to explore. Lock swatches with 1–5.
  3. Check the tonal ramps and the WCAG contrast grid for readable pairs.
  4. Turn on a colour-blind preview to test accessibility.
  5. Copy the result as CSS variables or JSON from Export.
